# 02 — Domain randomization

*Chaotic Curiosity | regolith series*

## Coming in this session

Wire up NVIDIA Omniverse Replicator to the lunar stage from chapter 01. Register randomizers that vary: sun elevation (5°–85°), sun azimuth (0°–360°), sun intensity, regolith albedo and texture, rock count (10–80 per frame), rock scale, rock placement, camera pose, and camera field of view. Generate a labeled training dataset of ~10 k frames — each frame paired with an RGB render, a semantic segmentation mask, an instance mask, and a depth map. Measure class distribution and confirm the `rock` class is well-represented.
